# Glossary — the freight vocabulary

A–Z of terms used in this course. Read it as you go; skim it at the end as revision.

| Term | Meaning |
|---|---|
| **Aframax** | Tanker ~700k barrels; crude & products, shorter hauls |
| **Ballast** | Sailing empty (no cargo) to pick up the next load — non-earning time |
| **Baltic Exchange** | London institution (owned by SGX since 2016) that publishes daily freight assessments |
| **BCI** | Baltic Capesize Index — Capesize TC routes (BCI 5TC) |
| **BDI** | Baltic Dry Index — the headline composite (weighted avg of BCI/BPI/BSI, ~40/30/30 since 2018) |
| **BHSI** | Baltic Handysize Index — Handysize TC routes (BHSI 7TC) |
| **BPI** | Baltic Panamax Index — Panamax TC routes (BPI 5TC) |
| **BSI** | Baltic Supramax Index — Supramax TC routes (BSI 10TC) |
| **Backwardation** | Forward curve declining — later months priced lower than spot |
| **Broker** | Intermediary matching ships to cargoes (physical) or FFA buyers/sellers (paper) |
| **C3** | Route: Brazil (Tubarão) → China, iron ore (~170k t) |
| **C5** | Route: W. Australia (Port Hedland) → China (Qingdao), iron ore (~170k t) |
| **Capesize** | Largest dry-bulk class (~150k–200k DWT); iron ore, coal; too big for the Panama Canal |
| **Charterer** | The party renting the ship (usually a cargo owner) |
| **Clearing house** | Guarantees settlement between FFA counterparties (SGX, ICE) |
| **Congestion** | Port queues / delays that tie up ships and tighten supply |
| **Contango** | Forward curve rising — later months priced higher than spot |
| **DWT** | Deadweight tonnes — max cargo a ship can carry |
| **FFA** | Forward Freight Agreement — cash-settled forward on a freight index |
| **Forward curve** | Prices of FFA months/quarters into the future |
| **Handysize** | Smallest dry-bulk class (~25k–45k DWT); niche cargoes, small ports |
| **Hedge** | Trade that reduces an existing exposure (owner locks earnings, charterer caps cost) |
| **Index number** | A points-based measure of a market (like the BDI), not a dollar price |
| **Lots** | Contract unit; 1 lot of a TC FFA = 1 day of TC rate |
| **Monthly average** | The settlement basis: average of daily index assessments in the contract month |
| **Orderbook** | Ships on order at shipyards — future supply arriving in 2–3 years |
| **Panamax** | Dry-bulk ~60k–85k DWT; coal, grains; fits the Panama Canal |
| **Panellist** | Freight broker whose route assessments feed the Baltic indices |
| **P3A** | Panamax transatlantic round-voyage route |
| **Q4 rally** | Seasonal late-year rise in dry-bulk rates (iron-ore restock, grain) |
| **Scrapping** | Recycling old ships — reduces fleet supply (esp. in weak markets) |
| **Slow steaming** | Sailing below full speed to save fuel — removes effective capacity |
| **Speculation** | Taking price risk for profit, without an underlying ship/cargo |
| **Spot vs forward** | Spot = today's rate; forward (FFA) = a price agreed now for a future month |
| **Sub-index** | One class's index (BCI, BPI…) that composes the BDI |
| **Suezmax** | Tanker ~1M barrels; crude |
| **Supramax / Ultramax** | Dry-bulk ~50k–64k DWT; grains, fertilizers, steel products |
| **TC rate** | Time-charter rate — $/day for the whole ship |
| **Tonne-mile** | Tonnes × distance — the real "demand" measure (a Brazil–China cargo consumes ~3× the capacity of an Australia–China one) |
| **Voyage rate** | $/tonne for a specific route/trip |
| **VLCC** | Very Large Crude Carrier (~2M barrels); Middle East → Asia crude |
