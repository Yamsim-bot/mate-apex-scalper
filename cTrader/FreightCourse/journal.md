# Freight Journal — daily BDI tracker

One line per day, every trading day. It takes 60 seconds: copy the BDI from any freight site, write the change, and name **one** driver from lesson 05. After 2–3 weeks you'll start seeing the patterns before the news explains them.

**Where to get the numbers (free):** tradingeconomics.com/commodity/baltic · investing.com/indices/baltic-dry · balticexchange.com · searching "Baltic Dry Index today".

## How to fill it in (30 seconds)

1. **BDI** — the headline composite, in points.
2. **Δ %** — change vs. the previous day (positive = stronger rates).
3. **Biggest mover** — which sub-index led the day: **BCI** (Capesize) / **BPI** (Panamax) / **BSI** (Supramax) / **BHSI** (Handysize).
4. **Driver** — one line: what moved it (lesson 05 categories: China/iron ore, seasons, weather, congestion, scrapping, Q4 restock…).

## Reading guide

- **BDI rising for weeks** → firm demand / tight supply → think "trend up" (Template: Trend).
- **BDI flat in a range** → balanced market → think "range" (Template: Range).
- **One class moving alone** → the story is specific (e.g. only BCI moving = iron ore story, not the whole market).
- **Q1 weakness / Q4 strength** is the classic seasonal pattern (lesson 05) — check the calendar before calling a move "news".
